## [1.0.0] - 2026-10-27

### Adicionado

- Reconstrução funcional documentada do agente
  Gerador Inteligente de Prompts.
- SKILL.md compatível com o formato Agent Skills.
- Fluxo guiado original com perguntas preservadas.
- Seleção de estilos de vídeo.
- Seleção entre rosto próprio e personagem.
- Tratamento de primeira pessoa com I/me.
- Estrutura final obrigatória de sete seções.
- Descrições de vídeo em inglês.
- Diálogos em português brasileiro.
- Linguagem cinematográfica ultra-realista.
- Suporte a estilos de animação.
- Modos Ultimate de revisão, storyboard,
  múltiplas tomadas e adaptação textual.
- Controle de continuidade visual.
- Tratamento de referências acessíveis.
- Auditoria funcional.
- Matriz de vinte testes.
- Exemplos práticos.
- Validador estrutural local.
- README de instalação e utilização.
- Licença MIT.

### Limitações iniciais

- Testes de equivalência ainda não executados.
- Sem integração direta obrigatória com geradores de vídeo.
- Sem mecanismo próprio de renderização.
- Suporte multimodal dependente do anfitrião.
- Validador local não substitui o validador oficial.
- Publicação no GitHub ainda pendente.

### Estado

Release documental inicial.
